# Personal Portfolio Website

This repository contains the source code for **Aayush Kumar’s** personal portfolio website hosted at **zen-ash.github.io**. The site is a clean, responsive, and fast static website built with plain HTML and CSS. It showcases featured projects, skills, education, and provides a way to contact Aayush.

## Sections

- **Hero:** Introduces Aayush with a status line and call‑to‑action button.
- **Featured Projects:** Highlights several projects with descriptions and links to live demos and source code.
- **Skills:** Lists languages, frameworks, and tools used.
- **Experience & Education:** Notes current education and internship availability.
- **Contact:** Provides email and GitHub links.

## Open Graph & Twitter Previews

The site includes OG/Twitter metadata and preview images stored in the `assets` directory (`og-image.png`, `twitter-image.png`). These improve sharing on social platforms.

## Sitemap

A `sitemap.xml` file is included at the root to help search engines crawl the site.

## Deployment

GitHub Actions is used to automatically deploy the site to GitHub Pages from the `main` branch. The workflow is defined in `.github/workflows/deploy.yml` and uses the [actions-gh-pages](https://github.com/peaceiris/actions-gh-pages) action.
